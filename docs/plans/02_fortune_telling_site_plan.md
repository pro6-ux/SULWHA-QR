# 오늘의 원소 운세 사이트 구현 계획서

주인님, 요청하신 이름, 생일, 성별을 입력받고 5대 원소(불, 물, 나무, 땅, 바람) 중 하나를 골라 오늘의 운세를 볼 수 있는 사이트의 구현 계획서입니다. 

사용자 정보를 안전하게 로컬에서만 처리하고, 보기만 해도 기분 좋아지는 고품격 디자인과 부드러운 애니메이션 효과를 적용하여 완성도 높게 제작하겠습니다.

---

## 사용자 검토 필요 사항

> [!NOTE]
> **보안 및 데이터 처리 안내**
> - 본 사이트는 사용자가 입력한 이름, 생년월일 등의 개인정보를 외부 서버로 전혀 전송하지 않고, 오직 브라우저 내부(메모리 상)에서만 운세 결과 계산용으로 사용합니다. 
> - 따라서 법적 규제나 유출 걱정 없이 안전하게 안심하고 이용하실 수 있습니다.

> [!TIP]
> **운세 매커니즘 제안**
> - 완전히 매번 바뀌는 단순 랜덤 방식보다는, **[이름 + 생년월일 + 오늘 날짜 + 선택한 원소]**를 조합한 고유 해시 코드를 기반으로 운세를 산출하도록 설계하겠습니다.
> - 이렇게 하면 **오늘 하루 동안은 언제 접속해도 동일한 "오늘의 운세" 결과**가 나와서 신뢰성을 줍니다. (단, 원한다면 결과를 다시 뽑을 수 있는 '다시 뽑기' 버튼도 함께 제공하겠습니다.)

## 제안하는 주요 기능 및 디자인 컨셉

1. **신비롭고 고급스러운 다크 글래스모피즘 테마**
   - 우주와 별자리를 연상시키는 깊은 다크 블루/퍼플 그라데이션 배경.
   - 투명한 유리 느낌의 카드 UI(Glassmorphism)와 부드러운 네온 글로우 효과.
   - Google Font 'Outfit' 또는 'Noto Sans KR'을 적용하여 세련된 타이포그래피 구현.

2. **직관적인 단계별(Step-by-Step) 입력 폼**
   - 1단계: 이름, 생년월일, 성별 입력.
   - 2단계: 5가지 원소 카드(불, 물, 나무, 땅, 바람) 중 하나 선택.
     * 불: 타오르는 오렌지-레드 네온 이펙트
     * 물: 맑고 투명한 블루 이펙트
     * 나무: 싱그러운 포레스트 그린 이펙트
     * 땅: 묵직하고 따뜻한 골드-브라운 이펙트
     * 바람: 가볍고 신비로운 시안-에메랄드 이펙트
   - 3단계: 화려한 로딩 연출 후 오늘의 운세 결과 공개.

3. **고급스러운 운세 결과 카드**
   - 종합 운세 지수 (별점 또는 게이지 바 형태)
   - 오늘의 원소 메시지 (원소의 성향과 결합한 맞춤 조언)
   - 운세 상세 (재물운, 연애운, 성공운)
   - 오늘의 행운 요소 (행운의 색상, 행운의 시간, 행운의 행동 등)

## 검증 계획 (Verification Plan)

### 수동 검증
1. 브라우저로 `index.html`을 연 후 모바일/데스크톱 화면에서 레이아웃이 깨지지 않는지 반응형 디자인을 확인합니다.
2. 필수 입력값(이름, 생일, 성별)을 누락하고 진행할 때 올바르게 경고 창이나 에러 메시지가 뜨는지 확인합니다.
3. 원소 카드를 클릭했을 때 해당 원소 고유의 컬러 테마로 결과 카드가 매끄럽게 연출되는지 확인합니다.
4. 동일한 이름과 생일로 당일 재조회 시 일관된 결과가 나오는지, '다시 뽑기'를 눌렀을 때 정상적으로 새롭게 운세가 갱신되는지 확인합니다.
